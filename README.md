# Sales-Forecasting-using-Time-Series-Analysis

## Objective
Predict future sales trends using historical data to improve inventory management and business planning.

## Models
**ARIMA**: Time series model for short-term linear trends.
**LSTM**: Deep learning model for capturing complex patterns. (Code included)

## Tools
Python, Pandas, NumPy, ARIMA (statsmodels), LSTM (TensorFlow/Keras), Matplotlib

## Structure
`data/` — Historical sales dataset
`images/` — Plots for Tableau-style dashboards
`scripts/` — Python scripts for ARIMA and LSTM
`notebooks/` — Analysis notebooks
